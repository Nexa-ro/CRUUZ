# Security Policy

## Reporting a Vulnerability

Please do not disclose suspected security vulnerabilities through public GitHub issues.

If you believe you have found a security issue affecting CRUUZ, report it privately to the project team with enough information to reproduce and assess the issue.

Please include, where applicable:

- The affected component or workflow
- A concise description of the issue
- Reproduction steps
- Potential impact
- Relevant logs or screenshots with secrets and personal data removed

Do not include passwords, API keys, access tokens, private user information, or other secrets in a report.

## Scope

CRUUZ is under active development. This public repository currently contains portfolio and product documentation rather than the complete application source. Security guidance will evolve as additional components are published.
